# Film Collection

Film Collection is a small Angular movie catalog application built with mock data.

## Features

- Film catalog
- Film details page
- Search by title
- Add to favorites
- Breadcrumbs
- Custom autofocus directive
- Custom duration pipe
- Angular Signals

## Technologies

- Angular
- TypeScript
- SCSS
- Angular Router
- Angular Signals

## How to run

```bash
npm install
ng serve
